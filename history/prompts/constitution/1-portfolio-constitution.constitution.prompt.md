# Prompt
```
Create a constitution for a professional, futuristic portfolio website that will showcase my work in an astonishing and world-class manner. This portfolio should:

CORE PRINCIPLES:
- Prioritize performance (90+ Lighthouse scores across all metrics)
- Embrace cutting-edge web technologies while maintaining accessibility
- Create memorable, interactive experiences without sacrificing usability
- Reflect innovation and technical excellence in every detail
- Maintain clean, maintainable production-ready code

TARGET AUDIENCE:
- Tech recruiters and hiring managers at top-tier companies
- Potential clients seeking premium development services
- Fellow developers and design professionals
- Industry thought leaders

TECHNICAL CONSTRAINTS:
- Must be responsive (mobile-first approach)
- Must meet WCAG 2.1 AA accessibility standards
- Must load initial view in under 2 seconds on 3G
- Must work across modern browsers (last 2 versions)
- Must be deployable to standard hosting (Vercel, Netlify, etc.)

DESIGN PHILOSOPHY:
- Futuristic aesthetic with purposeful animations
- Microinteractions that delight without distracting
- Bold typography and generous whitespace
- Sophisticated color palette with excellent contrast
- Seamless transitions between sections

Define the architectural approach, technology stack recommendations, design system principles, and success metrics for this portfolio.
```

# Response
```
The portfolio constitution has been created with six core principles:

1. Performance Excellence - Requiring 90+ Lighthouse scores and sub-2-second load times
2. Cutting-Edge Innovation with Accessibility - Balancing modern tech with WCAG 2.1 AA compliance
3. Delightful User Experience - Purposeful microinteractions and seamless transitions
4. Technical Excellence and Maintainability - Clean, well-documented production-ready code
5. Mobile-First Responsive Design - Progressive enhancement from mobile up
6. Futuristic Aesthetic - Bold, innovative design with sophisticated typography

The constitution also includes Technical Standards, Design System Principles, and Governance sections that align with your requirements for a world-class portfolio showcasing technical excellence.
```
