01. About Me

Hello! I'm Muhammad, a full-stack developer based in Karachi, Pakistan. I enjoy creating things that live on the internet — whether that's a full-scale web application, an interactive dashboard, or an API serving thousands of requests.

My journey into web development started 8 years ago when I built my first website. Since then, I've had the privilege of working with startups and established companies, helping them bring their digital products to life.

These days, my main focus is building accessible, performant, and scalable applications using modern technologies like React, Next.js, TypeScript, and Node.js. I'm also deeply interested in cloud-native architectures and DevOps practices.
